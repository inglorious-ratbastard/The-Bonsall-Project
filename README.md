##### **About This Repo:**

##### About This Repo:

##### The Bonsall Project began as an experimental web-development concept focused on creating a modern, visually engaging, and highly interactive user experience without relying on large application frameworks. Originally developed as a potential hackathon submission, the project was designed to demonstrate how thoughtful visual design, animation, and client-side technologies could be combined to create an engaging digital experience.

##### Following the passing of a close friend, **John Bridger Bonsall (1989–2019)**, the project took on a considerably more meaningful purpose. What began as a technical and creative exercise evolved into a project dedicated to his memory and to the broader cause of **depression awareness, mental-health awareness, and suicide prevention**.

##### The project is also dedicated to the memory of **Ethan Ryan Skipper (1997–2021)**, reflecting its continued commitment to remembering those whose lives have been affected by suicide and mental-health struggles.

##### The Bonsall Project combines software development with personal remembrance and advocacy. It is intended to demonstrate how technology can be used not only for creative expression, but also to communicate difficult subjects, encourage awareness, and create opportunities for meaningful conversations.

##### Technology Stack:

* ##### **HTML5** — Core page structure and semantic markup
* ##### **CSS3** — Custom styling, layout, responsive design, and visual presentation
* ##### **JavaScript** — Client-side functionality and interactive behavior
* ##### **GSAP** — Fluid animations and transition effects
* ##### **p5.js** — Interactive and generative visual experiences
* ##### **Material Design** — Primary design inspiration and visual language
* ##### **Font Awesome** — Icons and interface elements

##### The project intentionally uses **vanilla HTML, CSS, and JavaScript** rather than a major front-end framework, keeping the implementation lightweight, accessible, and easy to study or modify.

##### Ultimately, **The Bonsall Project is built around two complementary ideas: technology as a medium for creative expression, and technology as a means of preserving memory and encouraging meaningful conversations.**

##### **In memory of John Bridger Bonsall (1989–2019).**

##### **In memory of Ethan Ryan Skipper (1997–2021).**

##### **Features:**
* ##### Dynamic, fluid splash screen using the **GSAP** animation library
* ##### **Material Design** pattern inspired layout aesthetic 
* ##### Interactive components tooled with the **P5js** processing library
* ##### Ease of use/flow thru smooth scrolling and animation transitions
##### This site is build solely using HTML, CSS, and Javascript. No major frameworks have been used thus far. <br> The **Material Design** aesthetic was achieved by simply using Font Awesome and CSS styling.

##### Repository Structure:

##### The repository follows a lightweight, framework-free structure designed to keep the project's source code accessible and straightforward to navigate.

```
The-Bonsall-Project/
├── assets/
│   └── images/          # Project imagery and visual assets
│
├── .vscode/             # Visual Studio Code workspace configuration
├── .gitignore           # Git ignore rules
├── .replit              # Replit project configuration
├── CONTRIBUTING.md      # Contribution guidelines
├── README.md            # Project documentation
├── index.html           # Main application entry point
├── package.json         # Project metadata and dependencies
├── package-lock.json    # Locked dependency versions
├── replit.nix           # Replit environment configuration
├── script.js            # Client-side JavaScript and interactions
└── style.css            # Custom styling and visual presentation
```

##### The project intentionally keeps its core implementation separated into **HTML, CSS, and JavaScript**, with supporting assets organized within the `assets` directory. This structure allows the project to remain lightweight while making the primary components of the application easy to locate, understand, and modify.

##### Configuration files such as `package.json`, `.replit`, and `replit.nix` provide the supporting development and deployment configuration, while `CONTRIBUTING.md` documents the process for those interested in contributing to the project.
